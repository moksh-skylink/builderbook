BuilderBook Frontend Layout & Feature Guide

This mockup visualizes the complete frontend architecture of the BuilderBook ERP/CRM system:

1. Core Layout Structure:
  • Sidebar: Dynamic collapsed/expanded navigation with role filtering, colored module icons, and Skylink branding.
  • Header: Global command search (`⌘K`), quick-create menus, notifications dropdown, and live role badge.
  • Main Stage: Fluid 2-column or 3-column dashboard responsive layout with card statistics and tables.
2. Key Features Represented:
  • Payment Entry Register & Settlement: Receiver records collections on site with photo proof; Chartered Accountant (CA) or Admin settles entries with a 1-click confirmation workflow.
  • Inventory Matrix: Units categorized by status (Available, Booked, Sold) and configuration (2BHK, 3BHK, Retail Shop).
  • Real Estate Project Portfolio: Residential, Commercial, and Mixed-Use tracking with unit sales velocity.
  • Role-Based Access Control (RBAC): Admin, Receiver (Site Clerk), CA (Accountant), and Viewer.
